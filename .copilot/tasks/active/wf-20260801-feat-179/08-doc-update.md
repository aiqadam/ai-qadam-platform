Added a "Verification discipline" paragraph generalizing the lesson (a minted link returning 200/targeting the right flow is not sufficient proof — only an actual click-through to an authenticated `/me` call proves the stage topology is right) for future Authentik-flow-provisioning workflows. Two rows added to the existing `## 10. Pointers into the code` table (`magic-link.service.ts`/`authentik.client.ts`/the provisioning script; the `apps/web-next` UI files), matching that table's existing one-row-per-concept convention. |
